# Тестовый Android APK

## Как выпустить APK

1. Открыть GitHub repository.
2. Открыть **Actions**.
3. Выбрать **Выпустить тестовый APK**.
4. Нажать **Run workflow**.
5. Выбрать нужную ветку.
6. Нажать **Run workflow**.
7. После успешного завершения открыть созданный GitHub Release.
8. Скачать файл `Sportzal-test-....apk`.
9. Передать APK на Android или скачать непосредственно с телефона.
10. Разрешить Android установку приложений из этого источника, если система попросит.

> **Предупреждение.** Текущие APK используют временную debug-подпись. Пока постоянный signing key не настроен, следующая сборка может не установиться поверх предыдущей. В таком случае удалить предыдущую тестовую версию Sportzal и установить новую APK. Данные удалённого приложения при этом могут быть потеряны.

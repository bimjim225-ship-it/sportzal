# Проверка Sportzal 0.2.0

База: main 92089d5, включает PR41. Изменения находятся в отдельной ветке; main не изменялся.

## Уже проверено

- Исходная схема Room v1 экспортирована сборкой до изменения entities.
- Регрессия явного «Не оценил»: исходное падение assertion, после исправления 98/98 unit tests.
- Графика/каталог: 101/101 unit tests, debug APK и test APK собраны.
- Основной цикл/предпросмотр: 104/104 unit tests.
- Android API30, программный эмулятор: 27/27 Room tests, включая миграции v1→2 и v1→3 и атомарную запись конфигурации/схемы.
- Premium static audit: 0 findings. Он проверяет документы; Kotlin runtime подтверждается отдельной сборкой и инструментальными тестами.

## Текущая проверка

Итоговая сборка debug APK/test APK и 107/107 unit tests прошли. Lint и полный Compose suite ещё выполняются; результаты ниже дополняются после выполнения.

Независимое ревью выявило контекст последнего факта для схем и недоступный extra после последнего слота. Общий resolved context теперь выбирается целиком: draft → последний факт → план, включая намеренные null-поля. Регрессии actual context прошли unit suite. Исходный extra UI test воспроизвёл отсутствие диалога; проверка исправления включена в полный прогон.

Первый Back timeout диагностирован по screenshot/semantics: performScrollTo обращался к предварительно созданной trailing-кнопке LazyColumn, которая ещё не была размещена. ScrollToNode по контейнеру + assertIsDisplayed на неизменённом APK прошёл возврат, продолжение и пересоздание до отдельного ожидаемого падения на десятичном разделителе. UI теперь выводит 22,5; snapshot по-прежнему хранит число 22.5.

Состояние ошибки открытия тренировки получило Retry/Back вместо бесконечного индикатора; acceptance test сначала воспроизвёл отсутствие recovery control на старом APK.

## Границы поставки

Встроены пять типовых схем и по две позы движения; привязки явные. Автоматическая генерация по фото и установка внешних media-пакетов остаются следующим этапом. AI snapshot — обмен последними 24 завершёнными занятиями с focus/active, а не полный backup/restore. Реальный телефон, Share Sheet с конкретным получателем и TalkBack вручную не проверены в этой среде.

## Reconcile drift

| Правило | Было | Изменение |
|---|---|---|
| Согласованный mobile flow | Все формы раскрыты одновременно | Обзор и выбранное упражнение |
| Визуальный материал | Фото в основных карточках | Схема; фото в разделе исходника |
| Токены | Документация отрицала существующий runtime | Один Compose adapter, явные typography/shapes |
| Факт против плана | Общий счётчик saved.size | Плановые рабочие, разминка, extra, skip отдельно |
| Навигация | Неявное открытие активного занятия | Продолжить, Back с flush и сохранённым маршрутом |

## Ручная приёмка на телефоне

Перед повседневным использованием: установить APK, проверить обновление поверх существующих данных, системные жесты/клавиатуру, блокировку и возврат, реальный process death, отправку/сохранение JSON, открытие JSON из файлов, крупный шрифт и TalkBack. Это оставшиеся проверки, не утверждение о готовом релизе магазина.
